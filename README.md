# Tennis Scorecard

Installable tennis scoring web app. No sign-in; data stays on your device.

- Use it: see `COPILOT_SETUP_PROMPT.md` to publish it with GitHub Pages using Copilot.
- Develop: `npm install`, `npm run dev`. Check with `npm run typecheck` and `npm run build`.
- One-file version for opening from disk: `npm run single` creates `tennis-scorecard.html`.
- Details for contributors and Copilot: `.github/copilot-instructions.md`, `docs/FEATURES.md`.
