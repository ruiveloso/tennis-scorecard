# Features in this version

- **Score**: point-by-point scoring for singles and doubles; match or single-game mode; presets (standard, final-set tiebreak, advantage, pro set, Fast4, custom); serve tracking, change of ends and tiebreak cues, undo, point tags (ace, double fault, winner, error), spoken score announcements, big scoreboard view, suspend and resume, share the result as text. The scoreboard sits directly above the Quick scoring heading, blue/red cards and court. Blue/red quick-scoring cards with large +/− buttons work alongside the tappable court and stay in sync. Each player's − button only undoes the latest point if that player won it; the shared Undo button still works as before.
- **Setup**: remembers the last setup (format, players, first server, court, location) and shows "Using your last setup" with a reset.
- **Game and set summaries**: a silent pop-up pauses scoring after each newly completed game or set, including single-game mode and the final set. It shows the winner, set scores, points won in the game, next server, and any change of ends. The highlighted Next game / Next set / Start tiebreak button continues without altering the score; Finish closes the summary when play is complete. Edit score undoes the winning point and returns to scoring. The pop-up stays open until one of these actions is chosen, does not repeat when reopening a match, and works independently of Show cues.
- **Weather**: current conditions recorded with the match (Open-Meteo), metric or imperial, shown in the live header, history and shared text.
- **History**: list and map views, match details with statistics, weather and a pinned court location.
- **Court map**: built-in SVG map of pinned courts with distances; no map tiles.
- **Coach mode**: track set scores for several matches side by side and share all scores.
- **Guide**: rules and scoring help.
- **Settings**: announcer language and voice, cues, tags, court surface, weather options, Save backup and Import backup. Optional **Keep screen awake** (off by default) keeps the screen on while a live match is open on Score, including the big scoreboard. It releases when scoring is closed, suspended or finished, or when the app is hidden, and requests it again when the app becomes visible. Requires a supported browser and secure context (HTTPS or localhost); device battery-saving settings may refuse or release the lock.
- **Offline**: installable and works without signal after the first open (service worker, https only).
