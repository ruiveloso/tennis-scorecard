# Features in this version

- **Score**: point-by-point scoring for singles and doubles; match or single-game mode; presets (standard, final-set tiebreak, advantage, pro set, Fast4, custom); serve tracking, change of ends and tiebreak cues, undo, point tags (ace, double fault, winner, error), spoken score announcements, big scoreboard view, suspend and resume, share the result as text.
- **Setup**: remembers the last setup (format, players, first server, court, location) and shows "Using your last setup" with a reset.
- **Weather**: current conditions recorded with the match (Open-Meteo), metric or imperial, shown in the live header, history and shared text.
- **History**: list and map views, match details with statistics, weather and a pinned court location.
- **Court map**: built-in SVG map of pinned courts with distances; no map tiles.
- **Coach mode**: track set scores for several matches side by side and share all scores.
- **Guide**: rules and scoring help.
- **Settings**: announcer language and voice, cues, tags, court surface, weather options, Save backup and Import backup.
- **Offline**: installable and works without signal after the first open (service worker, https only).
